# ExcelKROAutoFormat

Программа автоматически форматирует Excel-сверки инвентаризации.

- Вход: файл сверки из 1С (`.xlsx`, лист `TDSheet`).
- Выход: файл сверки с подготовленным форматированием.
- Реализация: веб-приложение на Python. Развёртывание на удалённый сервер через SSH одной командой.

## Граница автоматизации

Программа делает автоматически:

- ремонт файла из 1С;
- разбор блоков групп;
- сдвиг шапки и геометрию;
- формулы итогов групп и общего итога;
- цветовые метки по введённым данным;
- имя выходного файла.

Пользователь вводит вручную в веб-форме: неучтёнку, контрольное число, дату `B3`, признак `C5`, метки `не+`, комментарии столбца `L`, блок сотрудников.

## Примеры

1. `ОхтаМоллСМА без форматироания.xlsx` — вход (склад ОхтаМоллСМА).
2. `ОхтаМоллСМА 09.09.2026.xlsx` — выход (тот же склад).
3. `БалтийскийТЦМДБ без форматирования.xlsx` — вход (склад БалтийскийТЦМДБ).
4. `БалтийскийТЦМДБ 09.09.2026.xlsx` — выход (тот же склад).
