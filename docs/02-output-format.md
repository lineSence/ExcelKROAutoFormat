# 2. Готовый файл (образец)

Примеры: `ОхтаМоллСМА 09.09.2026.xlsx` (81 строка), `БалтийскийТЦМДБ 09.09.2026.xlsx` (175 строк).

## 2.1 Имя файла

Шаблон: `<Склад> <ДД.ММ.ГГГГ>.xlsx`, например `ОхтаМоллСМА 09.09.2026.xlsx`.
Дата совпадает с датой из титула инвентаризации.

## 2.2 Шапка готового файла

Шапка сдвинута вверх на одну строку. Строка 1 освобождена для контрольного блока.

| Ячейка | ОхтаМоллСМА | БалтийскийТЦМДБ | Оформление |
| --- | --- | --- | --- |
| `B1` | `Неучтёнка 224,00` | `Неучтёнки нет` | заливка `FFFF00`, Arial 10 полужирный, рамка `medium` |
| `C1` | `5299?` | `1530?` | числовой формат `#,##0.00`, текст с `?` |
| `A2` | титул из 1С | титул из 1С | Arial 14 полужирный |
| `B3` | `17.08.2026` | `09.07.2026` | тип дата, формат `mm-dd-yy` |
| `A4` | `Склад:` | `Склад:` | Arial 9 |
| `C4` | `ОхтаМоллСМА` | `БалтийскийТЦМДБ` | Arial 9 полужирный |
| `C5` | — | `Планово` | Arial 9 |
| `H4` | `Валюта:` | `Валюта:` | текст сохранён, значение `руб` удалено |
| `I4` | `=SUM(J10,J23,J39,J47,J57,J71)` | `=SUM(J41,J86,J107,J130,J138,J161)` | заливка `FFFF00`, `#,##0.00`, рамка `medium`, по центру |
| `H5` | `С н. д/с` | — | Arial 8 |
| `I5` | `=I4+224` | — | заливка `92D050` (зелёная), `#,##0.00`, рамка `medium` |

`I4` — итог сверки: сумма итоговых ячеек всех групп в столбце `J`.
`I5` — итог с учётом неучтёнки (есть только там, где неучтёнка есть).

## 2.3 Блоки групп

Структура блока сохранена: заголовок (с объединением на две строки), данные, строка итога.

Изменения против 1С:

1. В строке итога группы удалены итоги в `D`, `E`, `F`, `K`.
2. В строке итога группы добавлена формула в `J`: `=SUM(J<первая>:J<последняя>)`.
   - Диапазон берётся с запасом: он включает пустые строки после данных (пример: `=SUM(J14:J22)` при данных 14–21).
   - Оформление: Arial 9 полужирный, `#,##0.00`, рамка `medium` со всех сторон, по центру.
3. В строках данных разобранные расхождения обнулены: `J = 0`.
4. Неразобранные расхождения оставлены и подсвечены.

## 2.4 Цветовые метки

| Цвет | Код | Где | Смысл (по примерам) |
| --- | --- | --- | --- |
| жёлтый | `FFFF00` | `F` и `J` строки данных | расхождение не разобрано, `J` не обнулён |
| оранжевый | `FFC000` | `F` строки данных | строка с меткой `не+` в `C`, `J = 0` |
| жёлтый | `FFFF00` | `B1`, `I4` | контрольные ячейки |
| зелёный | `92D050` | `I5` | итог с неучтёнкой |

## 2.5 Служебные пометки

- Столбец `C`: текст `не+` вместо характеристики или в пустой ячейке.
- Столбец `L`: комментарии `неучтёнка`, `неучтёнка ПДВ`, `перетарка`.
- Автофильтр установлен на столбец `K` (например `K1:K81`).

## 2.6 Блок сотрудников (подвал)

После тела сверки добавлен блок распределения суммы по сотрудникам. Пример (ОхтаМолл, строки 71–81):

| Строка | `B` | `C` |
| --- | --- | --- |
| 71 | `Гаврилова Людмила Сергеевна` | `=I5/B81` |
| 72 | `12` | `=C71*B72` |
| 73 | `Зайнетдинова Анастасия Дмитриевна` | |
| 74 | `122` | `=C71*B74` |
| … | … | … |
| 81 | `407` (сумма всех чисел) | |

Правила:

- Строки чередуются: ФИО, затем число (вес сотрудника).
- Первая ячейка `C` — ставка на единицу веса: итог / общий вес.
- Остальные `C` — ставка × вес сотрудника.
- ОхтаМолл делит `I5` (итог с неучтёнкой), Балтийский делит `I4` (неучтёнки нет).
- Последняя строка `B` — общий вес (делитель).

## 2.7 Геометрия готового файла

- Ширина столбцов изменена: A 5,83; B 55,83; C 5,83; G 10,83; K 61,33; L 55,83. Остальные столбцы по умолчанию.
- Высота строк: 12 пт (вместо 22 пт в 1С).
- Ориентация страницы: портрет, A4.
