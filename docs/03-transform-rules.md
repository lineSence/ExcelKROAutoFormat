# 3. Правила преобразования

Порядок шагов для программы. Шаги 1–9 делает программа. Шаги 10–12 делает человек в Excel.

## Шаг 1. Ремонт файла

В архиве `.xlsx` из 1С нет части `xl/sharedStrings.xml`, поэтому `openpyxl` не откроет файл.

Способ ремонта: вставить в архив пустой `xl/sharedStrings.xml` и запись о нём в `[Content_Types].xml` и в связи листа. Прочие части архива не меняются, поэтому стили, ширины и границы из 1С сохраняются полностью.

Конвертация через LibreOffice запрещена как основной способ: она перезаписывает стили и ширины. Она остаётся запасным вариантом и включается настройкой `REPAIR_MODE=libreoffice`.

## Шаг 2. Разбор структуры

1. Найти титул: ячейка в `A`, которая начинается с `Инвентаризация товаров`.
2. Из титула извлечь номер документа и дату инвентаризации.
3. Взять имя склада из имени входного файла: это часть до первого пробела либо часть до слова `без` (пример: `ОхтаМоллСМА без форматироания.xlsx` → `ОхтаМоллСМА`). В шапке файла 1С значение склада пустое, поэтому другого источника нет. Способ задаётся настройкой `WAREHOUSE_SOURCE`.
4. Найти все строки заголовков групп: `A = "№"` и `C = "Хар-ка"`.
5. Для каждого блока определить: имя группы (`B` заголовка), первую и последнюю строку данных, строку итога (первая строка после данных без значения в `A`, но с числами в `D`/`E`/`F`).

## Шаг 3. Сдвиг шапки

1. Удалить строку `Организация:`.
2. Поднять титул в строку 2, блок `Склад:` в строку 4, первый заголовок группы в строку 6.
3. Заполнить `C4` именем склада из шага 2 (полужирный).
4. Удалить значение `руб` рядом с `Валюта:`.
5. Оставить строку 1 и ячейки `B3`, `C5`, `I5` пустыми для ручного ввода.

## Шаг 4. Поиск пересортов

В каждой группе товаров собрать позиции одного бренда в гроздь и разобрать расхождения по итогу грозди. Цена не проверяется: столбец `G` справочный. Полное правило: `06-resort-rules.md`.

Кратко:

1. Итог `F` по грозди неотрицательный и есть минусы и плюсы — рамка вокруг `F`, `J = 0`, заливки нет.
2. Итог `F` по грозди отрицательный — жёлтая заливка `F` и `J` в минусовых строках, значение `J` из 1С остаётся (идёт в минус).
3. Итог `F` положительный и минусов нет — оранжевая заливка `F`, в `C` метка `не+`, `J = 0`.

## Шаг 5. Итоги групп

В каждой строке итога:

1. Очистить `D`, `E`, `F`, `K`.
2. Записать в `J` формулу `=SUM(J<первая строка данных>:J<строка перед итогом>)`. Диапазон включает пустые строки между последней строкой данных и строкой итога.
3. Задать формат: Arial 9 полужирный, `#,##0.00`, рамка `medium`, выравнивание по центру.

## Шаг 6. Общий итог

В `I4` записать `=SUM(<список итоговых ячеек J через запятую>)`. Заливка `FFFF00`, рамка `medium`, `#,##0.00`, Arial 10 полужирный.

## Шаг 7. Подсветка остальных расхождений

1. Заливка ставится как постоянный стиль ячейки, без условного форматирования.
2. Если `J` не равно нулю и строка не обработана шагом 4 (например `F` пустое, а `J` нет), залить `F` и `J` жёлтым.
3. Строки шапок и итогов не подсвечивать.

## Шаг 8. Геометрия и фильтр

1. Установить ширину столбцов: A 5,83; B 55,83; C 5,83; G 10,83; K 61,33; L 55,83.
2. Установить высоту строк 12 пт.
3. Включить автофильтр на столбец `K` от строки 1 до последней строки (`K1:K<последняя>`), как в образце.
4. Сохранить границы и шрифты из 1С без изменений, кроме рамок пересорта из шага 4.

## Шаг 9. Имя выходного файла

`<Склад> <ДД.ММ.ГГГГ>.xlsx`. Склад — из шага 2, дата — из титула.

## Шаг 10. Проверка пересортов и спорные строки (вручную)

Человек проверяет решения программы по отчёту о гроздях и правит спорные строки: снимает жёлтую заливку, ставит метки вручную.

## Шаг 11. Контрольные ячейки `B1`, `C1`, `B3`, `C5`, `I5` (вручную)

Источники этих данных вне файла 1С. Дата в `B3` вводится как дата в формате `ДД.ММ.ГГГГ`.

## Шаг 12. Блок сотрудников (вручную)

ФИО и веса в файле 1С отсутствуют. Список в базе не хранится.

## Запреты для программы

1. Не менять порядок строк. Поиск пересорта — только расчёт, без перемещения строк.
2. Не добавлять пустые строки в группы.
3. Не удалять строки данных и не править столбцы `A`, `B`, `D`, `E`, `F`, `G`, `H`, `I`, `K`.
4. Менять `J` и `C` только по правилам шага 4.

## Наблюдения по примерам

В образцах есть ручные правки содержания, а не только форматирования. Программа их не воспроизводит:

1. ОхтаМолл: строка `2168 Сигареты Некст Виолет` перенесена ниже строк `2188`/`2189`.
2. Балтийский: в строке 38 добавлен товар без кода в `A` и без документа в `K`, с пометкой `неучтёнка ПДВ` в `L`.

Важно: из-за ручных правок полное совпадение с образцом недостижимо. Тесты сравнивают только структуру, формулы и стили.
