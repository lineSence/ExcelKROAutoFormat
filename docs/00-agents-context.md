# 00. Контекст разработки для агентов

Главная память проекта лежит в корне репозитория:
**[`agents_context.md`](../agents_context.md)**.

С него начинается любая работа по проекту — и у человека, и у ИИ-агента.

## Короткое правило

1. Перед любой правкой кода прочитать `agents_context.md` целиком и сверить
   с ним свой план.
2. Каждое изменение поведения, структуры, настроек, развёртывания или
   внешних сервисов записать туда же в том же коммите.
3. При расхождении файла и кода прав код — файл надо сразу поправить.
4. Найденные причины ошибок добавлять в таблицу граблей (раздел 8).
5. Ключи, токены, пароли и данные сверок в файл не попадают никогда.
