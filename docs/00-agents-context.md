# 00. Контекст разработки для агентов

Главная память проекта лежит в корне репозитория:
**[`agents_context.md`](../agents_context.md)**.

С него начинается любая работа по проекту — и у человека, и у ИИ-агента.

## Короткое правило

1. Перед любой правкой кода прочитать `agents_context.md` целиком и сверить с ним свой план.
2. Каждое изменение поведения, структуры, настроек, развёртывания или внешних сервисов записать туда же в том же коммите.
3. При расхождении файла и кода прав код — файл надо сразу поправить.
4. Найденные причины ошибок добавлять в таблицу граблей (раздел 8).
5. Ключи, токены, пароли и данные сверок в файл не попадают никогда.

## Актуальные дополнения

Подробное описание новых пользовательских настроек и UI-автоматизации находится
в [`docs/13-ui-and-settings.md`](13-ui-and-settings.md):

- режим разбора по умолчанию (`off`, `model`, `llm`) сохраняется в `runtime.json`;
- POST-формы получают индикатор выполнения без внешних JavaScript-библиотек;
- длинные списки, карточки и таблицы сворачиваются на уровне представления;
- на `/update` можно выбрать ветку Git, которая сохраняется отдельно в каталоге OTA.

Актуальное устройство выбора ветки и последствия `check`/`apply` описаны также в
[`docs/09-ota-update.md`](09-ota-update.md).

Остальные файлы `docs/` — подробности по отдельным темам. Контекст из
`agents_context.md` главнее в вопросах правил работы и требований владельца.
