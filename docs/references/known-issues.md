# Грабли

Случаи, на которые уже наступали. Каждая строка связана с правилом в `docs/rules/`.
Новая строка появляется в том же коммите, что и исправление (`[DEV-DOCS-SAME-COMMIT]`).

## Веб-слой

| Симптом | Причина и лечение | Правило |
| --- | --- | --- |
| `Method Not Allowed` после POST | `meta refresh` без `url=` повторяет POST | `[WEB-REFRESH-URL]` |
| Страница грузится бесконечно | ответ ждал всех шагов; нужен билет | `[WEB-BACKGROUND]` |
| Служба не отвечает ни на что | блокирующий код в `async def` | `[WEB-THREADPOOL]` |
| Пункт меню отвечает 404 | шаблон без маршрута | `[WEB-NAV]` |
| Форма молча не сохраняет | потеряно скрытое поле `token` | `[WEB-TOKEN-FIELD]` |
| «Разбор не найден» после перезапуска | состояние в памяти, так задумано | `[WEB-STATE-MEMORY]` |
| Выгрузка файлов ломалась | промежуточный слой был на `BaseHTTPMiddleware` | `[ASGI-PURE]` |
| Компаньон взял недописанный файл | нужны `*.part`, `replace`, `stable_seconds` | `[WEB-ATOMIC-FILE]` |

## Предметная часть

| Симптом | Причина и лечение | Правило |
| --- | --- | --- |
| Излишек покрашен как недостача | излишек определяется по нулевой разнице сумм | `[DOM-SURPLUS]` |
| Рамка пересорта пропала при пересборке | пометки строятся заново, не переносятся | `[DOM-REBUILD-MARKS]` |
| Порог поменяли в коде | порог и полоса — настройка, не константа | `[DOM-THRESHOLD]` |
| Пометка «нет фото» не там, где ждали | ставится только при положительном итоге | `[DOM-NO-PHOTO]` |

## Настройки и состояние

| Симптом | Причина и лечение | Правило |
| --- | --- | --- |
| Настройка не сохраняется | поле не добавили в `FIELDS` | `[CFG-FIELDS]` |
| Настройки пропали после обновления | файл лежал в `/opt/excelkro` | `[CFG-STATE-PATH]` |
| Пустое поле стёрло ключ | пустое = «оставить как было», есть кнопка очистки | `[CFG-EMPTY-KEEPS]` |
| Дефолты в коде и в примере окружения разные | сверки не было | `[ENV-SYNC]` |

## Внешние модели и почта

| Симптом | Причина и лечение | Правило |
| --- | --- | --- |
| Папка почты не находится | имя надо кодировать в modified UTF-7 | `[AI-MAIL-MATCH]` |
| В сверку попали чужие снимки | ящик общий, нужна связка по складу | `[AI-MAIL-MATCH]` |
| Снимки разбирались повторно и тратили квоту | нужны `only_new` и предел 12 | `[AI-ONCE-PER-JOB]` |
| Сверка упала из-за модели | отказ должен быть молчаливым | `[AI-SILENT-FALLBACK]` |
| Счёт за судью вырос | нужны пределы на файл и на процесс плюс кэш | `[AI-LIMITS]` |
| `httpx` понадобился на сервере | его там нет, только `urllib` | `[AI-STDLIB-NET]` |

## Развёртывание и инструменты

| Симптом | Причина и лечение | Правило |
| --- | --- | --- |
| `Permission denied` при запуске скрипта | право `+x` не сохранилось; звать через `bash` | `[OTA-EXEC-BIT]` |
| Обновление убивало себя на перезапуске | нужен отдельный юнит | `[OTA-UNIT]` |
| Служба виснет в `deactivating (stop-sigterm)` | фоновые задачи не отменяются | `[OTA-STUCK]` |
| Файл в коммите оказался обрезан | длинные вызовы с кириллицей обрываются | `[DEV-TOOL-TRUNCATION]` |
| Поиск по коду ничего не находит | индекс репозитория пуст | `[DEV-NO-CODE-SEARCH]` |
