# 1. Входной файл из 1С

## 1.1 Файл и лист

- Формат: `.xlsx`.
- Лист: один, имя `TDSheet`.
- Столбцы: `A`…`L` (данные в `A`…`K`, столбец `L` служебный, ширина 0,5).
- Шрифт: Arial. Заголовки групп 9 пт, данные 8 пт, титул 14 пт полужирный.

## 1.2 Важно: файл 1С технически неполный

В архиве `.xlsx` нет части `xl/sharedStrings.xml`.

Следствия:

- Библиотека `openpyxl` открывает файл с ошибкой `KeyError: 'xl/sharedStrings.xml'`.
- Перед чтением файл надо восстановить. Варианты: конвертация через LibreOffice/Excel, либо добавление пустого `sharedStrings.xml` в архив.

## 1.3 Шапка документа

| Ячейка | Значение в примерах |
| --- | --- |
| `A3` | `Инвентаризация товаров на складе по группам № 1574 от 09 сентября 2026 г.` |
| `A5` | `Организация:` (значение пустое) |
| `A6` | `Склад:` (значение пустое) |
| `H6` | `Валюта:` |
| `J6` | `руб` |

## 1.4 Блок группы товаров

Тело сверки — это последовательность блоков. Один блок — одна группа товаров.

Структура блока:

1. Строка заголовка таблицы (объединена по вертикали на две строки, например `B8:B9`).
2. Пустая строка (вторая строка объединения).
3. Строки данных.
4. Строка итогов группы: суммы в `D`, `E`, `F` и `K`, полужирный шрифт 9 пт.
5. Пустые строки перед следующим блоком.

### Столбцы заголовка

| Столбец | Заголовок | Содержание |
| --- | --- | --- |
| `A` | `№` | код номенклатуры |
| `B` | имя группы | наименование товара |
| `C` | `Хар-ка` | характеристика (часто цена или пусто) |
| `D` | `Кол-во по учету` | количество в 1С |
| `E` | `Кол -во` | фактическое количество |
| `F` | `Итого` | разница количества (`E` − `D`) |
| `G` | `Цена` | цена |
| `H` | `Сумма` | фактическая сумма |
| `I` | `Сумма по учету` | сумма в 1С |
| `J` | `Разница сумма` | разница суммы |
| `K` | `Документ движения` | последний документ по товару |

### Пример расположения блоков

Файл `ОхтаМоллСМА без форматироания.xlsx` (78 строк):

| Группа | Заголовок | Данные | Итоги |
| --- | --- | --- | --- |
| IQOS/GLO | 8 | 10 | 12 |
| Подарки и сувениры | 15 | 17–24 | 26 |
| Сигареты | 29 | 31–41 | 43 |
| Сопутствующие Товары | 46 | 48–50 | 52 |
| Табачная продукция | 55 | 57–61 | 63 |
| Электронка | 66 | 68–76 | 78 |

Файл `БалтийскийТЦМДБ без форматирования.xlsx` (164 строки) имеет такую же схему, но набор и порядок групп другой.

**Вывод для программы:** номера строк жёстко задавать нельзя. Блоки надо искать по признаку `A№ = "№"` и `C№ = "Хар-ка"`.

## 1.5 Форматы чисел в входном файле

| Столбец | Формат |
| --- | --- |
| `A` | `#,##0` или `0` |
| `D`, `E`, `F` | `0` |
| `G`, `H`, `I`, `J` | `#,##0.00` |

## 1.6 Границы и выравнивание

- Внешние границы таблицы: `medium` (слева в `A`, справа в `J` и `K`, сверху в строке заголовка).
- Внутренние границы: `thin`.
- Заголовки: по центру, перенос текста в узких столбцах.
- Данные: `A` по центру, `B`, `C`, `K` влево с переносом, числа вправо.
- Высота строк данных: 22 пт.
- Ширина столбцов (ОхтаМолл): A 6,34; B 34,0; C 7,34; D 6,66; E 6,5; F 7,17; G 8,0; H 8,66; I 9,34; J 11,5; K 61,34; L 0,5.

## 1.7 Вторая выгрузка: продавцы и часы

Отдельный необязательный файл на один склад (правило `[DOM-SELLERS-FILE]`).
Разбор — `app/core/sellers.py`, поле формы загрузки — `sellers`.

Строение образца (лист `TDSheet`, строки объединены по `A:C`):

| Ячейка | Значение |
| --- | --- |
| `A2` | `Параметры:` |
| `C2` | `Дата кон: 15.09.2026 23:59:59` |
| `C3` | `Дата нач: 11.08.2026 0:00:00` |
| `A4` | `Отбор:` |
| `C4` | `Склад Равно "ИмяСклада"` |
| `A6` | `Продавец` |
| `A7`, `A8` | `Часы` (заголовок может повторяться) |
| `A9`, `A10` | ФИО первого продавца и его часы (формат `0`) |
| … | дальше такие же пары |
| последняя строка | итог часов без ФИО |

Что из этого следует для разбора:

- Номера строк не фиксированы: текстовая строка — ФИО, следующая
  числовая — его часы.
- Число без ФИО перед ним — итог, в список продавцов он не попадает.
- Служебные строки (`Параметры`, `Отбор`, `Дата нач`, `Дата кон`,
  `Склад`, `Валюта`) и заголовки (`Продавец`, `Часы`, `Итого`,
  `Всего`, `Сотрудник`) пропускаются.
- Имя склада берётся из строки отбора и пока используется только для
  заметок: склад сверки по-прежнему берётся из имени файла сверки
  (`[DOM-WAREHOUSE]`).
- Файл тоже приходит без `xl/sharedStrings.xml`, поэтому перед чтением его
  ремонтирует `repair()` — тот же путь, что у сверки (пункт 1.2).
- Часы принимаются и с запятой (`12,5`), и с разделителями тысяч.
