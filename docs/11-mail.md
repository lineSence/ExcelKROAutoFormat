# 11. Почта ревизоров: приём фото и сообщений

Ревизоры присылают снимки плюсующего товара письмом. Раздел «Почта
ревизоров» (`/mail`) забирает такие письма из ящика, складывает вложения на
сервер и показывает, что удалось понять из текста. Решение по каждому
снимку по-прежнему принимает человек.

## Что нужно завести

1. Отдельный почтовый ящик для фото (по умолчанию Mail.ru). Основной
   рабочий ящик сюда подключать не стоит: пароль лежит в настройках службы.
2. **Пароль приложения** этого ящика, а не пароль от учётной записи.
   В Mail.ru он создаётся в настройках безопасности ящика, в Яндексе —
   в разделе «Пароли приложений».
3. Заполнить блок «Настройки ящика» на странице `/mail` и поставить
   галочку «Включить приём почты».

Никаких файлов на сервере править не нужно: все значения сохраняются
в `runtime.json` (см. `agents_context.md`, раздел 4).

## Настройки

| Поле формы | Ключ в `runtime.json` | По умолчанию |
| --- | --- | --- |
| Сервер IMAP | `mail_host` | `imap.mail.ru` |
| Порт | `mail_port` | `993` |
| Почтовый ящик | `mail_login` | пусто |
| Пароль приложения | `mail_password` | пусто |
| Папка ящика | `mail_folder` | `INBOX` |
| Адреса ревизоров | `mail_senders` | пусто (все) |
| Глубина поиска, дней | `mail_since_days` | `7` |
| Предел писем за заход | `mail_max_letters` | `20` |
| Предел снимков за заход | `mail_max_photos` | `40` |
| Предел размера снимка, МБ | `mail_max_photo_mb` | `15` |
| Ожидание сервера, секунд | `mail_timeout` | `30` |
| Хранить снимки, дней | `mail_keep_days` | `7` |
| Только непрочитанные | `mail_only_unseen` | да |
| Помечать прочитанными | `mail_mark_seen` | да |
| Включить приём почты | `mail_enabled` | нет |

Пустое поле пароля означает «оставить как было». Отдельная кнопка
«Удалить пароль» стирает его из настроек. Пустой список адресов
записывается принудительно: иначе белый список нельзя было бы снять.

## Как идёт заход в ящик

1. Кнопка «Проверить ящик» (`POST /mail/check`) — вход, открытие папки и
   подсчёт писем к разбору. Ничего не скачивается.
2. Кнопка «Забрать почту» (`POST /mail/fetch`) — вход, поиск писем
   (`UNSEEN` и/или `SINCE`), чтение каждого письма, сохранение вложений
   в `mail-photos/<номер письма>/NN-имя.jpg`, затем очистка снимков старше
   `mail_keep_days`.
3. Номера разобранных писем пишутся в `mail-state.json` (последние 1000),
   поэтому повторный заход то же письмо не тянет. Флаг «прочитано» для
   этого ненадёжен: ящик смотрит и человек.
4. Письма последнего захода живут в памяти процесса (`MAIL_LETTERS`
   в `app/main.py`) и показываются на странице. Перезапуск службы список
   стирает, сами снимки остаются на диске.

Письма забираются только по кнопке. Фоновый сбор не нужен: состояние
сверок живёт в памяти процесса, и складывать результат было бы некуда.

## Что вытаскивается из текста

`mail.read_hints()` ищет только то, что находится без всякой модели:

- коды товара — подряд идущие 5–10 цифр;
- количество — «3 шт», «10 штук», «2 уп»;
- магазин — «магазин 47», «маг. Ульянка», «тт Думская»;
- слова письма — «излишек», «недостача», «пересорт», «брак», «списание»,
  «возврат», «бой», «фото».

Это подсказки для человека, а не решение. Сопоставление снимка со строкой
сверки делает раздел «Фото товара» (`docs/10-photo-vision.md`): пока
скачанный снимок нужно сохранить по ссылке на странице почты и загрузить
туда вручную.

## Маршруты

| Маршрут | Что делает |
| --- | --- |
| `GET /mail` | страница раздела |
| `POST /mail/settings` | сохранение настроек, редирект 303 |
| `POST /mail/check` | проверка ящика без скачивания |
| `POST /mail/fetch` | заход за письмами и вложениями |
| `POST /mail/password/clear` | удаление пароля из настроек |
| `GET /mail/photo/{uid}/{name}` | отдача скачанного снимка |

Имена файлов чистятся `mail.safe_name()`, а путь снимка дополнительно
сверяется с папкой `mail-photos`: письмо может принести имя вида
`../../etc/passwd`.

## Что бывает не так

| Сообщение | Причина |
| --- | --- |
| «Ящик не пускает: проверьте логин и пароль приложения» | введён основной пароль ящика вместо пароля приложения, либо приём по IMAP не включён в настройках ящика |
| «Папка … не найдена в ящике» | папка с русским именем; надёжнее разбирать `INBOX` |
| «Почтовый сервер … не отвечает» | нет сети или закрыт порт 993 |
| «Новых писем нет» после переустановки | номера писем помнит `mail-state.json`; удалите файл, чтобы разобрать письма заново |
| «вложение … больше N МБ» | снимок крупнее `mail_max_photo_mb`; ревизору проще переслать его отдельным письмом |

## Тесты

`tests/test_mail.py` работает без сети: вместо ящика подставляется
заглушка через аргумент `opener` у `mail.check()` и `mail.collect()`.
Проверяются разбор письма с вложением, подсказки из текста, белый список
адресов, чистка имён файлов, сохранение снимков, пределы и пропуск уже
разобранных писем.
