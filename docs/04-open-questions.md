## 4.1 Решено

### R1. Ручные данные

Все данные из вопросов Q1–Q7 вводятся вручную. Источники разные и вне файла 1С.

Список ручных полей:

| Поле | Ячейка | Пример |
| --- | --- | --- |
| Неучтёнка | `B1` | `Неучтёнка 224,00` или `Неучтёнки нет` |
| Контрольное число | `C1` | `5299?` |
| Дата | `B3` | `17.08.2026` |
| Признак инвентаризации | `C5` | `Планово` |
| Сумма неучтёнки для итога | `I5` | `=I4+224` |
| Метка `не+` | `C` строки данных | `не+` |
| Обнуление разницы | `J` строки данных | `0` |
| Комментарий | `L` строки данных | `неучтёнка` |
| Блок сотрудников | подвал, `B` и `C` | ФИО и число |

Правила для программы:

1. Программа не выводит эти данные сама.
2. Программа берёт их из веб-формы и ставит в нужные ячейки.
3. Программа сама применяет связанное форматирование: цвета, рамки, формулы.
4. Если поле не заполнено, ячейка остаётся пустой, а цветовая метка не ставится.
5. Автоматизация источников — задача будущих версий.

### R2. Среда работы

Веб-приложение на Python. Развёртывание на удалённый сервер через SSH. Установка максимально автоматическая. Результат — готовый к работе сайт. Подробности: `05-architecture.md`.
