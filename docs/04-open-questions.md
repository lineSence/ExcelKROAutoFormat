# 4. Ответы и оставшиеся вопросы

Дата последних ответов: 11.09.2026.

## 4.1 Решено

### R1. Ручные данные

Все данные из вопросов Q1–Q7 вводятся вручную. Источники разные и вне файла 1С. Автоматизация источников — задача будущих версий.

| Поле | Ячейка | Пример | Где вводится |
| --- | --- | --- | --- |
| Неучтёнка | `B1` | `Неучтёнка 224,00` | в Excel |
| Контрольное число | `C1` | `5299?` | в Excel |
| Дата | `B3` | `17.08.2026` | в Excel |
| Признак инвентаризации | `C5` | `Планово` | в Excel |
| Итог с неучтёнкой | `I5` | `=I4+224` | в Excel |
| Метка `не+` | `C` строки данных | `не+` | в Excel |
| Обнуление разницы | `J` строки данных | `0` | в Excel |
| Комментарий | `L` строки данных | `неучтёнка` | в Excel |
| Блок сотрудников | подвал, `B` и `C` | ФИО и число | в Excel |

### R2. Среда работы

Веб-приложение на Python. Сервер: Ubuntu Server. Подробности: `05-architecture.md`.

### R3. Граница работы сайта

1. Сайт делает только преобразование файла. Формы для ручных полей нет.
2. Пользователь загружает файл 1С, скачивает готовый файл и дозаполняет его в Excel.
3. Список сотрудников в базе не хранится.
4. Входа по паролю нет.
5. История файлов не хранится. Файлы удаляются сразу после выдачи.
6. База данных не нужна.

### R4. Доступ

1. Служба слушает только `127.0.0.1`.
2. Домена нет, HTTPS не нужен, Nginx не нужен.
3. Доступ через SSH-туннель. Адрес в браузере: `http://localhost:8000`.

### R5. Формат даты

В `B3` остаётся формат `mm-dd-yy` как в образце.
