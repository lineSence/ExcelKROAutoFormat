# 4. Ответы и оставшиеся вопросы

Дата последних ответов: 11.09.2026. Открытых вопросов нет.

## 4.1 Решено

### R1. Ручные данные

Все данные ниже вводятся вручную в Excel. Источники разные и вне файла 1С. Автоматизация источников — задача будущих версий.

| Поле | Ячейка | Пример |
| --- | --- | --- |
| Неучтёнка | `B1` | `Неучтёнка 224,00` |
| Контрольное число | `C1` | `5299?` |
| Дата | `B3` | `17.08.2026` |
| Признак инвентаризации | `C5` | `Планово` |
| Итог с неучтёнкой | `I5` | `=I4+224` |
| Метка `не+` | `C` строки данных | `не+` |
| Обнуление разницы | `J` строки данных | `0` |
| Оранжевая заливка | `F` строки `не+` | `FFC000` |
| Комментарий | `L` строки данных | `неучтёнка` |
| Строки товаров без кода | любое место | вставка вручную |
| Блок сотрудников | подвал, `B` и `C` | ФИО и число |

### R2. Среда работы

Веб-приложение на Python. Сервер: Ubuntu Server. Подробности: `05-architecture.md`.

### R3. Граница работы сайта

1. Сайт делает только преобразование файла. Форм для ручных полей нет.
2. Пользователь загружает файл 1С, скачивает готовый файл и дозаполняет его в Excel.
3. Список сотрудников в базе не хранится.
4. Входа по паролю нет.
5. История файлов не хранится. Файлы удаляются сразу после выдачи.
6. База данных не нужна.

### R4. Доступ

1. Служба слушает только `127.0.0.1:8000`. Порт `8000` на сервере свободен.
2. Домена нет, HTTPS не нужен, Nginx не нужен.
3. Доступ через SSH-туннель. Адрес в браузере: `http://localhost:8000`.

### R5. Формат даты

В `B3` остаётся формат `mm-dd-yy` как в образце.

### R6. Предварительная подсветка расхождений

Программа заливает жёлтым `F` и `J` во всех строках данных, где `J` не равно нулю. Заливка постоянная, без условного форматирования. Человек снимает подсветку с разобранных строк. Подробности: шаг 6 в `03-transform-rules.md`.

### R7. Строки данных

1. Порядок строк из 1С сохраняется полностью. Программа не сортирует и не перемещает строки.
2. Пустые строки в группы не добавляются. Строки товаров без кода вставляет человек.
