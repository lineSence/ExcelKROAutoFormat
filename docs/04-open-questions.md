# 4. Ответы и оставшиеся вопросы

Дата последних ответов: 11.09.2026.

## 4.1 Решено

### R1. Ручные данные

Все данные ниже вводятся вручную в Excel. Источники разные и вне файла 1С.

| Поле | Ячейка | Пример |
| --- | --- | --- |
| Неучтёнка | `B1` | `Неучтёнка 224,00` |
| Контрольное число | `C1` | `5299?` |
| Дата | `B3` | `17.08.2026` |
| Признак инвентаризации | `C5` | `Планово` |
| Итог с неучтёнкой | `I5` | `=I4+224` |
| Комментарий | `L` строки данных | `неучтёнка` |
| Строки товаров без кода | любое место | вставка вручную |
| Блок сотрудников | подвал, `B` и `C` | ФИО и число |

Важно: метка `не+`, обнуление `J` и цветные заливки теперь ставятся автоматически (см. R8). Человек только проверяет результат.

### R2. Среда работы

Веб-приложение на Python. Сервер: Ubuntu Server. Подробности: `05-architecture.md`.

### R3. Граница работы сайта

1. Сайт делает только преобразование файла. Форм для ручных полей нет.
2. Список сотрудников в базе не хранится.
3. Входа по паролю нет.
4. История файлов не хранится.
5. База данных не нужна.

### R4. Доступ

1. Служба слушает только `127.0.0.1:8000`. Порт свободен.
2. Домена нет, HTTPS и Nginx не нужны.
3. Доступ через SSH-туннель: `http://localhost:8000`.

### R5. Формат даты

В `B3` остаётся формат `mm-dd-yy` как в образце.

### R6. Подсветка расхождений

Заливка — постоянный стиль ячейки, без условного форматирования.

### R7. Строки данных

1. Порядок строк из 1С сохраняется полностью.
2. Пустые строки в группы не добавляются.

### R8. Автоматические пересорты

Программа сама ищет пары пересорта внутри группы: одинаковый бренд, равная цена `G`, значения `F` равны `-1` и `+1`.

1. Пара найдена: рамка вокруг `F`, `J = 0`, без заливки.
2. Пары нет и `F` минус: жёлтая заливка, `J` из 1С остаётся (в минус).
3. Пары нет и `F` плюс: оранжевая заливка, метка `не+` в `C`, `J = 0`.

Полное правило: `06-resort-rules.md`.
