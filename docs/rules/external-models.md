# Правила: внешние модели и сеть (`AI-*`)

Зрелость: `validated`, кроме отмеченных `core`.
Подробности — `docs/07-ml-verifier.md`, `docs/10-photo-vision.md`,
`docs/11-mail.md`.

## `[AI-ADVISOR]` core: ИИ — подсказчик, решает человек

Любое распознавание товара и любое решение по пересорту подтверждает
человек. Режим с нулевым влиянием логики — инструмент проверки
качества моделей, а не способ отдать разбор машине.

## `[AI-PROVIDERS]` Сервисы, недоступные из РФ, не применяем

- Зрение — только **GigaChat (Сбер)**. Прямые Google Gemini и OpenAI
  отклонены.
- **Исключение от 14.09.2026 (разрешение владельца):** OpenRouter
  допустим для двух задач второго слоя — эмбеддинги имён и
  LLM-судья (`verify_mode=llm`). На зрение исключение не
  распространяется.
- Новый внешний сервис без разрешения владельца не добавляем.

## `[AI-OFF-BY-DEFAULT]` Второй слой выключен по умолчанию

Провайдер векторов по умолчанию — локальный ONNX, `verify_mode=off`,
влияние логики 100%. Включает человек в интерфейсе.

## `[AI-STDLIB-NET]` Сеть в серверном коде — только `urllib`

В `requirements.txt` нет `httpx`/`requests` и добавлять их нельзя.
`httpx` разрешён только компаньону (`requirements-companion.txt`).
Почта — `imaplib` и `email` из стандартной библиотеки.

## `[AI-DETERMINISTIC-FIRST]` Запросы к моделям — только по делу

Перед отправкой снимков в нейросеть данные должны быть связаны
детерминированно. Из текста писем берутся только детерминированные
подсказки (`mail.read_hints`) — никакой модели на этом шаге.

## `[AI-MAIL-MATCH]` Письмо связывается со сверкой до отправки фото

Ящик один на службу, поэтому `app/core/mail_match.py` делит письма на
свои и чужие по названию склада (`MIN_PART` 4, `MIN_RATIO` 0,82).
Совпадений нет — запросов к модели не делаем вовсе, причина
пишется текстом (`mail_match.NO_MATCH`). Ручная кнопка «Отправить на
разбор» связкой не ограничена, но при несовпадении пишет
предупреждение.

## `[AI-ONCE-PER-JOB]` Снимки разбираются один раз

Разбор снимков писем идёт при обработке сверки, а не при скачивании
архива. Названные снимки пропускаются (`only_new=True`), за заход —
не больше `mail_vision.LIMIT` (12) снимков. Ручная кнопка снимает
оба предела.

## `[AI-LIMITS]` Пределы трат обязательны

- `embed_max_requests` — на процесс (`EmbedLimit`), дальше сверка идёт
  без эмбеддингов.
- `judge_max_pairs` — на файл, `judge_max_requests` — на процесс,
  пары идут пачками `judge_batch`, лучшие кандидаты слоя 1 — первыми.
- Кэш ответов судьи — по нормализованным именам пары
  (`plus.key=>minus.key`), а не по номерам строк: пересборка почти не
  тратит запросы.

## `[AI-SILENT-FALLBACK]` Ошибка модели не ломает сверку

Ошибка эмбеддера — молчаливый отказ (`Verifier._embed_cos` работает
без признака). Нет ответа судьи — `Verdict.known=False`, пару решает
логика. Причина всегда видна в `LlmJudge.last_error` и журнале службы.

## `[AI-NO-NET-TESTS]` Тесты без сети

Ящик подменяется аргументом `opener`, распознавание — аргументом
`recognizer`, сервер для компаньона — `FakeClient`. Новый сетевой код
добавляется сразу с точкой подмены.
