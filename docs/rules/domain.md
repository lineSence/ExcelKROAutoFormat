# Правила: предметная область (`DOM-*`)

Зрелость: `validated`. Менять только по просьбе владельца:
за каждым пунктом стоит требование бухгалтерии, а не вкус разработчика.

## `[DOM-COLUMNS]` Столбцы файла сверки

| Столбец | Содержимое |
| --- | --- |
| A | код |
| B | наименование |
| C | характеристика (метка `не+` для излишка) |
| D | учёт |
| E | факт |
| F | итого, шт. |
| G | цена |
| H | сумма |
| I | сумма по учёту |
| J | разница сумм |
| K | документ движения |
| L (12) | служебный комментарий, сюда же пишется «нет фото» |

Лист с данными — `TDSheet` (настройка `SHEET_NAME`).

## `[DOM-SURPLUS]` Излишек не даёт плюса по сумме

У излишка `J = 0`. Заливка `FFC000`, в столбце C метка `не+`.

## `[DOM-COLORS]` Оформление строк

- Пересорт: рамка `medium` цвета `FF000000` вокруг ячейки `F`.
- Неполный пересорт и недостача: заливка `FFFF00`.
- Излишек: заливка `FFC000`.

## `[DOM-THRESHOLD]` Пороги схожести

Авторешение — от 0,80. Полоса сомнения 0,70–0,90 уходит на ручную
сверку человеку. Подробности — `docs/06-resort-rules.md`.

## `[DOM-NO-PHOTO]` Пометка «нет фото»

Пометку в столбце L получают все плюсующие строки (`F > 0`) без
подтверждённого снимка. Отмечается именно отсутствие фото, а не
наличие. Если в столбце уже есть текст — дописываем через запятую
(`photo_mark.apply()`).

## `[DOM-REBUILD-MARKS]` Пометки ставятся после каждой сборки

Пересборка от исходника (в том числе `claims.apply`) пишет столбец 12
заново, поэтому строки с подтверждённым фото хранятся в `Job.photo_rows`,
а пометки проставляются заново после каждой сборки файла
(`services/photos.py` из `services/upload_job.py`). История —
`docs/references/known-issues.md`.

## `[DOM-EXPORT-BY-HAND]` Выгрузка только по кнопке

Готовая сверка уходит на рабочий компьютер только после всех
подтверждений и только по нажатию человека. Заливка входящего
файла из папки может быть автоматической.

## `[DOM-WAREHOUSE]` Склад сверки

Название склада берётся из шапки (`Job.warehouse`) и служит
связкой со письмами ревизоров (`[AI-MAIL-MATCH]`) и именем архива
снимков `Фото_<склад>_<дата>.zip`.
