# 5. Архитектура и развёртывание

Решение: веб-приложение на Python на удалённом сервере. Установка через SSH одной командой.

## 5.1 Сценарий работы пользователя

1. Пользователь открывает сайт.
2. Загружает файл сверки из 1С.
3. Сайт ремонтирует файл, разбирает блоки групп и показывает сводку: склад, дата, группы, строки с расхождениями.
4. Пользователь заполняет ручные поля (список в `04-open-questions.md`, раздел R1).
5. Сайт собирает готовый файл и даёт его скачать.
6. Имя файла: `<Склад> <ДД.ММ.ГГГГ>.xlsx`.

## 5.2 Состав приложения

| Слой | Назначение | Инструмент (предложение) |
| --- | --- | --- |
| веб-слой | страницы, загрузка и выгрузка файлов | FastAPI + Jinja2 |
| ядро | ремонт файла, разбор, форматирование | `openpyxl` |
| хранение | списки складов и сотрудников, история файлов | SQLite |
| сервер приложения | запуск кода | Uvicorn под systemd |
| веб-сервер | внешние запросы, HTTPS | Nginx |

Ядро не зависит от веб-слоя. Его надо вызывать и из командной строки для тестов.

## 5.3 Структура репозитория (план)

```
app/
  main.py            веб-маршруты
  core/
    repair.py        ремонт xlsx из 1С
    parse.py         поиск блоков групп
    format.py        форматирование и формулы
    style.py         цвета, рамки, ширины
  templates/         страницы
  static/            стили
deploy/
  install.sh         установка на сервере
  deploy.sh          запуск установки через ssh
  app.service        юнит systemd
  nginx.conf         конфиг Nginx
  .env.example       настройки
tests/
  data/              примеры входа и выхода
docs/
```

## 5.4 Развёртывание через SSH

Одна команда на рабочей машине:

```bash
./deploy/deploy.sh user@server
```

Шаги скрипта `install.sh` на сервере:

1. Проверка ОС и прав `sudo`.
2. Установка пакетов: Python, Nginx, LibreOffice (если ремонт файла делается конвертацией).
3. Создание служебного пользователя и каталога `/opt/excelkro`.
4. Копирование кода и создание виртуального окружения.
5. Установка зависимостей из `requirements.txt`.
6. Запись `.env` из образца.
7. Установка юнита systemd и автозапуск.
8. Настройка Nginx и (при наличии домена) HTTPS через certbot.
9. Проверка работы: запрос к `адрес/health`.
10. Вывод адреса готового сайта.

Требования к скриптам:

- Повторный запуск безопасен (идемпотентность).
- Обновление версии той же командой.
- Все настройки в `.env`, без правки кода.
- Логи в journald.

## 5.5 Тесты

1. Проверка ремонта файла из 1С.
2. Проверка поиска блоков на двух примерах (6 групп в ОхтаМолл, другой набор в Балтийском).
3. Сравнение результата с образцом: адреса формул, цвета, ширины столбцов, автофильтр.
