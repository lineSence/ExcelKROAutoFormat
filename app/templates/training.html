4. LLM как второй слой

{{ judge.reason if judge else "Состояние неизвестно." }}

Внешний сервис: имена товаров, цены и количества пар уходят выбранному провайдеру, каждый запрос тратит его баланс. Режим выключен по умолчанию — он включается на странице загрузки выбором «Логика + LLM». Если эмбеддинги имён включены, их близость попадает в подсказку модели: так LLM работает в связке с ними.

GigaChat — тот же сервис Сбера, что и для распознавания фото: нужен ключ авторизации и модель вроде GigaChat-2, адрес запроса при этом не используется.

Пустое поле — оставить ключ как было. Для OpenRouter это ключ API, для GigaChat — ключ авторизации (Authorization key). Ключ хранится только в настройках службы и на странице не показывается. При смене провайдера ключ нужно ввести заново.

Для OpenRouter — например openai/gpt-4o-mini, для GigaChat — GigaChat-2. Дешёвые модели отвечают хуже — это и есть предмет проверки.

По умолчанию https://openrouter.ai/api/v1/chat/completions. Менять нужно только для другого совместимого сервиса; для GigaChat поле не используется.

Повтор идёт только при обрыве связи или ответах 429 и 5xx: ошибку ключа или модели повтором не исправить.
