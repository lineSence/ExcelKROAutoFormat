3. Настройки

Всё задаётся здесь и сохраняется в файле настроек программы. Править .env и перезапускать службу не нужно. Сохранение настроек не стирает разобранные снимки.

Берётся в личном кабинете GigaChat (строка Authorization key). Версия API подбирается сама: сначала для физических лиц, затем B2B и корпоративная. Ключ хранится на сервере, на странице целиком не показывается.

По умолчанию GigaChat-2. Модель должна уметь работать с изображениями.

У бесплатной версии есть предел обращений: пауза не даёт в него упереться.

Если модель не назвала номер строки, имя подбирается по прочитанному тексту не ниже этой схожести.

4. Обслуживание

Проверка связи ничего не распознаёт: она только убеждается, что ключ, версия API и модель рабочие.
