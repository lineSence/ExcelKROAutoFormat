# Контекст агента (L0)

Это единственный файл, который читается всегда и целиком.
Остальное знание подгружается по маршрутизатору
[`docs/_routing.md`](docs/_routing.md); карта всего знания —
[`docs/_index.md`](docs/_index.md). Протокол работы со знанием —
[`docs/00-agents-context.md`](docs/00-agents-context.md).

## О проекте

Веб-служба для ревизора: принимает выгрузку сверки из 1С,
приводит её к рабочему виду (столбцы, цвета, пересорт, пометки
«нет фото»), подтягивает снимки из почты и отдаёт файл по кнопке.
Python, FastAPI, Jinja2, openpyxl; сервер — VPS и systemd.

## Четыре правила, нарушение которых — регрессия

1. **Настройки — в интерфейсе.** Всё, что меняет ревизор — пороги,
   режимы, ячейки шапки, ключи моделей, почта — настраивается
   страницами и хранится в `runtime.json`. Переменные окружения
   задают только админский слой: адрес, доступ, пределы, каталоги
   (`[CFG-UI-FIRST]`, `[CFG-TWO-LAYERS]`).
2. **В репозитории нет ключей и данных сверок.** Ни в коде, ни в
   тестах, ни в документации, ни в памяти агента
   (`[SEC-NO-SECRETS]`).
3. **ИИ — подсказчик, решает человек.** Модели ничего не
   подтверждают сами, второй слой проверки выключен по умолчанию,
   выгрузка — только по кнопке (`[AI-ADVISOR]`,
   `[AI-OFF-BY-DEFAULT]`, `[DOM-EXPORT-BY-HAND]`).
4. **Язык — русский, ошибка понятна ревизору.** Интерфейс, ошибки,
   документация и правила — по-русски, без `Internal server error`
   и трассировок (`[WEB-RU-MESSAGES]`, `[WEB-NO-500]`, `[SEC-ERRORS]`).

Внешние сервисы — только доступные из РФ: зрение — GigaChat;
OpenRouter разрешён исключением от 14.09.2026 только для эмбеддингов
и LLM-судьи (`[AI-PROVIDERS]`).

## Категории знания

## Цикл роста знания (кратко)

Наблюдение → `docs/memory/inbox.md` (`draft`) → при повторе или
подтверждении кодом агент сам продвигает запись в
`docs/rules/` (`validated`) → в `core` только по явному «да» владельца.
Промоут отмечается в журнале и сообщением `📚 Promoted: [TAG]`.
Любое правило отменяется командой `/revoke [TAG]`.

## Как работать

- Коммиты по умолчанию в `main`; крупные правки — ветка и PR
  (`[DEV-MAIN-DEFAULT]`).
- Правка поведения — с тестом в `tests/` и с правкой знания в том
  же коммите (`[DEV-TESTS-REQUIRED]`, `[DEV-DOCS-SAME-COMMIT]`).
- Код главнее записи, кроме правил со зрелостью `core`: там
  исправляется код (`[DEV-CODE-WINS]`).
